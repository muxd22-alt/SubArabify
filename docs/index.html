No SRT? No Problem.

When English subtitles are included natively, SubArabify instantly bridges the gap via high-speed AI translation. But if a movie has no subtitles? It dynamically hooks into FFmpeg, aggressively rips the vocal track, and builds entirely new Arabic subtitles from raw audio.

Ruthlessly Smart Detection.

Your library is messy. SubArabify doesn't care. It recursively detects TV series hierarchies, flawlessly maps weirdly-named files to their corresponding `eng.srt`, or intelligently matches them to the exact TV episode name dynamically. Every file mapped flawlessly.

Never Works Twice.

Why waste compute on what's already done? SubArabify actively hashes file trees to detect existing Arabic translations. If the heavy lifting is already verified, it instantly skips the file, conserving maximum resources for unmatched speed.

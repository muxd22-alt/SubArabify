How it works

Your phone only scans, routes and uploads. The Colab T4 does the heavy lifting.

1 · Start the backend

Open the notebook in Colab, Runtime → Run all on a T4. It installs transformers + FastAPI, loads the Arabic Whisper variant and opus-mt-en-ar, and prints a free public tunnel URL when ready.

2 · Pick your library folder

Grant access once via Android's folder picker. Paste the tunnel URL into the Backend card — it shows online the moment the health probe succeeds (HTTP is fine).

3 · Scan, and let it route

Run a scan or leave monitoring on. Each video: already has Arabic? skip. Has an English .srt? uploaded for translation. Nothing at all? the audio track is extracted (no FFmpeg) and sent for direct Arabic transcription.

4 · Preview & play

Check the result inside the app as normal subtitles, then open the video in your player — *.SubArabify.ar.srt loads by name. A 2 h movie takes about 15–20 min on the T4.

Subtitle signature

Visible where it belongs. Quiet where it doesn't. Timings never touched.

Start Short SubArabify cue — only if a real gap exists before cue #1
Middle — free Your dialogue only. No watermark
End Short SubArabify cue ~1.5 s after the last line
Filename Always ends with .SubArabify.ar.srt

☁️ Backend — free Google Colab T4

One hidden notebook drives the whole app. Open it in Colab, run all, and paste the tunnel URL it prints.

1 · Open the notebook & run all

Colab → Runtime → Run all (GPU = T4). Models download once (~5 min), then the FastAPI backend boots.

https://colab.research.google.com/github/muxd22-alt/SubArabify/blob/main/backend/SubArabify_Backend.ipynb

2 · Paste the printed URL into the app

The last cell prints a free Cloudflare quick-tunnel URL — paste it into the Backend card and hit Save. The card flips to online. HTTP addresses are accepted.

https://snake-branches-restlessly-travel.trycloudflare.com

3 · Or drive it from any machine (Python client)

Only needs requests — video → 16 kHz WAV → upload → poll → branded *.SubArabify.ar.srt next to the file. Resume with --job after a disconnect.

python client/client.py --url https://xxxxxxxx.trycloudflare.com --media /path/to/movies

API: POST /jobs (multipart: srt= translate / file= transcribe) → GET /jobs/{id} → GET /jobs/{id}/srt. Full walkthrough in backend/README.md.

Be clear about limits

Honest beta notes.

  • Jobs run on the Colab session you started — if the free tier sleeps (idle ~90 min) or the tunnel drops, the app retries and a later scan can resume a job server-side
  • Your movie's audio or subtitle is uploaded to that tunnel endpoint — it's a temporary public address from Colab, not a SubArabify-owned server
  • Models re-download on a fresh Colab session (the notebook installs everything each run)
  • Current APK is a debug-signed beta from CI, not a Play Store build

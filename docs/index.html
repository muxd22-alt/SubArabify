How it works

Three steps. No cloud pipeline.

Pick your library folder

Grant access once via Android's folder picker. Movies, TV, Downloads — any tree. The small Arabic model downloads once, then everything is offline.

Translate (now or on a schedule)

Run a scan or leave monitoring on. SubArabify finds subtitle sources and translates them with memory — re-scans don't re-translate.

Preview & play

Check the result inside the app as normal subtitles, then open the video in your player — *.SubArabify.ar.srt loads by name.

Subtitle signature

Visible where it belongs. Quiet where it doesn't. Timings never touched.

Start Short SubArabify cue — only if a real gap exists before cue #1
Middle — free Your dialogue only. No watermark
End Short SubArabify cue ~1.5 s after the last line
Filename Always ends with .SubArabify.ar.srt

📺 Jellyfin addon — same engine, on your server

Native Python companion: normal media servers and Android via Termux (no .NET needed). Downloads the small Arabic model once, then writes *.SubArabify.ar.srt with untouched timings.

1 · Register the repository

Jellyfin → Dashboard → Plugins → Repositories → New Repository. Paste the manifest URL (a github.com/…/tree/… page link will not load):

https://muxd22-alt.github.io/SubArabify/jellyfin-manifest.json

2 · Enable on Termux (Android)

One command — model downloads on enable, then a full scan:

bash jellyfin-addon/run-termux.sh ~/storage/movies

3 · Or enable on a normal server

pip install -r jellyfin-addon/requirements.txt
python jellyfin-addon/subarabify_jellyfin.py --media /media --watch

Full usage in jellyfin-addon/README.md — systemd unit included. The catalog entry carries the SubArabify icon + version; enabling happens via the companion because Jellyfin can only Install .NET plugins.

Be clear about limits

Honest beta notes.

  • Needs an existing subtitle source (any .srt/.vtt, fuzzy-matched) — speech-to-text from audio is not ready yet
  • Model downloads once (needs network that first time), then 100% offline; repeats served from memory
  • Current APK is a debug-signed beta from CI, not a Play Store build
